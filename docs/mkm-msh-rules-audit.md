# MKM / MSH 規則複核（2026-10-24）

結論：先前並非所有機制都與牌面一致。本次核對卡池、可直接匹配的 Oracle 鏡像文字，以及費用、連續效果、力量加成、觸發限制與持續期限，修正下列可重現差異。這不是全部 547 張牌的所有規則分支或跨系列組合認證。

| 系列／牌 | 先前差異 | 修正行為 |
| --- | --- | --- |
| MKM — Demand Answers | 可選自己支付棄牌費用；付款方式可能受無關神器參數影響 | 禁止棄咒語本身，選擇棄牌時確實棄另一張手牌；犧牲方式只走既有神器付款流程 |
| MKM — Lost in the Maze | 受益生物失去自身異能時，錯誤移除外部賦予的護咒 | 橫置生物仍受迷宮的靜止式異能影響 |
| MKM — Living Conundrum | 空牌庫設定 10/10 時，抹除其他力量／防禦力加成 | 先設定基礎身材，再加指示物與加成 |
| MKM — Burden of Proof | 設為 1/1 時，抹除其他加成 | 基礎 1/1 加上指示物與其他加成 |
| MSH — Super-Soldier Serum | 以進場觸發永久修改宿主類別，光環離場仍留下類別 | 以連續效果賦予傳奇／Soldier，傳奇規則及篩選即時採用；離場停止，複製不攜帶此額外類別 |
| MSH — Namor / Super-Adaptoid / Ms. Marvel | 動態力量覆蓋其他力量加成 | 先計算基礎力量，再套用指示物、光環與暫時加成 |
| MSH — The Sensational She-Hulk | 拒絕第一次可選傷害仍消耗整回合次數 | 實際選擇造成傷害才消耗；已使用時不重複造成傷害 |
| MSH — Spider-Woman, Secret Agent | 來源失去控制權或離場重進後，原有禁止重置可能繼續生效 | 記錄來源的控制者與物件版本；期限結束後不恢復，異能重置也採用相同判定 |

## 來源與核對範圍

牌面資料沿用 [MKM 來源說明](mkm.md) 與 [MSH 來源說明](msh.md)：Forge 的 Oracle 欄位與部分 XMage 交叉核對；它們是公開規則資料鏡像，不能稱為 Wizards 官方 API 認證。此次重新比對可直接按牌名匹配的 Forge 文字，沒有發現文字差異。未直接匹配的連體牌合併名稱、Fanatical Strength、Kellan 與 Guerrilla Gorilla 沿用先前記錄的個別來源，不將它們算成這次直接匹配通過。

## 驗證

新增 9 個有實際對戰狀態斷言的回歸案例。MKM 22 項、MSH 29 項，合計 51 項通過，含主系列 271 / 276 張與補充包卡池核對。型別檢查與正式建置通過。追加蜘蛛女的期限案例前，完整回歸為 436 項通過、1 項既有跳過；追加後的兩系列 51 項專項測試通過，最後提交由 GitHub Pages 工作流程再次執行完整測試及建置。

尚未全面驗證的範圍仍包含連續效果的完整時間戳與相依排序、所有取代效果及同時觸發的玩家排序、複製與控制權變動的所有組合。因此不能把「全部卡片有實作」或這次測試通過說成「547 張在所有情境均與官方完全一致」。
