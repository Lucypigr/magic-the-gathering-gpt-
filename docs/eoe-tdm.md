# EOE / TDM 補卡進度

本批新增 EOE 27 張、TDM 28 張。卡池目前為 EOE 139 / 261、TDM 162 / 271；**兩系列仍未補齊**。逐張缺卡清單與可用數量見 [進度資料](eoe-tdm-progress.json)。數量包含相同牌名的跨系列重印，不包含基本地與替代插畫的重複版本。

新增與本批覆核的定義集中在 `src/data/sets/orbit-extra.ts`。未完成的卡片僅保留於完整來源目錄，不會以空白效果加入卡池。`ORBIT_BATCH` 明列本批套用的牌號；本批之外既有的複雜卡片尚不能視為已逐張覆核。

本批修正續戰可選指示物或 N/N 精怪（精怪本身不帶 +1/+1 指示物，且套用衍生物加倍），預兆結算後洗回牌庫、被反擊則進墓地，及新增卡片的虛空、動員、復新與部分跨系列互動。動員的衍生物橫置且攻擊，於下一個結束步驟犧牲。

英文費用、類別、規則文字與完整卡表取自 `scripts/localization/name-sources.json` 鎖定版本並驗證 SHA-256 的 MTGJSON 鏡像；不將自動解析失敗視為完成。中文名稱優先使用有刊印依據的名稱，其餘使用 [MTGZH 中文化魔風資料](https://github.com/HeliumOctahelide/magic-cards-zhs/releases/tag/data-2026-10-18) 中非 AI、已經人工處理的名稱及規則文字，透過 OpenCC 轉為繁體。`scripts/localization/eoe-tdm-rules.json` 保存英文對照、來源、原檔行號與識別碼；545 個有規則文字的來源牌面皆找到英文完全一致的中文對照。

`tests/eoe-tdm.test.ts` 檢查本批牌面資料與中文來源，並以實際施放、結算測試續戰選擇、衍生物加倍、預兆與反擊、武具附著、虛空傷害、神器進出場、躍遷延遲權限、動員、復新關鍵字指示物、守護生命及傳紀延遲觸發。這些代表性測試不等於窮舉所有牌組互動。

僅修改 GPT 版專案；卡圖與圖片載入設定未改動。
