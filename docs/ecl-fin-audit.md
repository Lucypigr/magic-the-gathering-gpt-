# ECL／FIN 跨系列互動測試

本次新增 `tests/ecl-fin-interactions.test.ts`，以 25 個指定案例檢查 ECL、FIN 與部分既有系列的互動，並將發現的錯誤保留為回歸測試。

## 測試及修正

- 傷害：Collective Inferno、Trance Kuja、繫命與 Wind Crystal 的連動；凋萎傷害先加倍，再放置負指示物。修正多隻 Ancient Adamantoise 重導時只處理第一個效果的問題，各效果在同一事件只套用一次。
- 衍生物：Mirrormind Crown、Quina 與神器改為龍的取代效果可選擇套用順序；同一事件不重複套用同一效果。檢查多個 Crown、拒絕其中一個，以及 Crown 在本回合已派出衍生物後才進場的情況。
- 複製：修正複製冒險咒語時取錯牌面、複製 evoke 咒語遺失選擇，以及複製 Omni-Changeling／Mirrorform 產物時取回原始牌面的問題。不複製指示物、暫時身材及實際支付法力。
- 雙面牌：複製已轉化的 Brigid 與 FIN 傳紀時保留另一面；新傳紀從自己的第一章開始。修正衍生物離開戰場後可被放逐返場效果帶回的問題。
- 指示物及離場：檢查 persist、終命、Earth Crystal、Blossombind、失去異能及 Morningtide's Light 的組合。
- 傳奇規則：FIN 的重名傳奇永久物可選擇保留哪一個，不再自動保留較新的複製品。

規則依據包括 CR 111.8（離場衍生物不能再次移動）、707.8a（轉化衍生物複製品）、707.10（咒語複製）、614.5 與 616.1（取代效果的重複限制及選擇順序）。這些測試驗證指定情境，並非逐張官方裁定認證。

## 驗證範圍

本次全專案回歸結果為 386 項通過、1 項沿用既有跳過；其中包含上述 25 個互動測試。TypeScript 型別檢查與正式建置通過，瀏覽器可進入練習對戰的起手牌選擇畫面，沒有 JavaScript 錯誤。

尚未窮舉所有卡片組合。連續效果的完整層次與相依性、其他複製／融合組合，以及所有傷害取代效果的玩家排序仍有未覆蓋範圍；例如多個 Adamantoise 目前依戰場順序重導，尚未提供選擇順序的介面。不能把這 25 個案例通過解讀為全引擎完全符合所有官方裁定。
